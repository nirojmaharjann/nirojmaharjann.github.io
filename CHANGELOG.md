## [2.4.0] - 2026-08-24 — Click-through fixes, mail icon, richer floating background (`2319803`)

### Fixed
- **Dead clicks on the SSL/TLS checkbox and mail icon (root cause):** the decorative
  floating-background layer declared `pointer-events: none` on its container only —
  its animated, filter-composited child spans could still win hit-testing in real
  browsers and silently swallow clicks. The layer and every child now enforce
  `pointer-events: none !important`.
- Interactive zones (resource chips, generator fields, tabs, action rows, footer
  socials) are pinned to `z-index: 2` with `pointer-events: auto` as a permanent
  counter-guard.
- Dropped `will-change` from floater spans; animations remain transform/opacity only.

### Changed
- Floating background expanded from 12 to 44 tech icons (JS, TS, Node, Python, Java,
  Go, C++, C#, PHP, React, Vue, Angular, HTML, CSS, Sass, GraphQL, webhooks,
  Docker, Kubernetes, Terraform, Ansible, AWS, Azure, GitHub, GitLab, Linux,
  console, API, network, security, database, cloud and more) arranged in three
  depth layers — far (blurred + dimmed), mid, near — with an ultra-slow rotation
  on every third icon.
- Responsive reduction: tablet hides the far layer, mobile hides far + near;
  `prefers-reduced-motion` still disables the layer entirely.
- Mail icon (all 52 pages + generator template): tooltip added on top of the
  existing configured `mailto:` action; hover lift with accent glow, press
  feedback and a visible keyboard-focus ring.

### Verified
- Full SSL/TLS cycle end-to-end: chip toggles config card, Ingress TLS block appears
  with derived secret name, unchecking removes it from YAML, deselecting SSL leaves
  zero cert-manager output.
- KUBERNETES suite grew 44 → 52 assertions; full battery green (193 total).

## [2.3.0] - 2026-08-24 — Kubernetes Manifest Generator (`791bfbe`)

### Added
- Resource-driven rewrite of the Deployment generator: one `RES` registry drives
  fields, validation and YAML for 9 resource types — Deployment, Service, Ingress,
  ConfigMap, Secret, SSL/TLS (existing secret or cert-manager), HPA, Namespace, PVC.
- "Select Kubernetes Resources" checkbox grid with Select all / Clear all; only
  selected resources render configuration cards.
- Smart linking: derived names recompute live until manually overridden
  (`app-service`, `app-ingress`, `app-config`, `app-secret`, `app-tls`, `app-data`);
  Service selector matches Deployment labels; Ingress points at the Service;
  TLS secrets flow into the Ingress; ConfigMaps/Secrets plug into `envFrom` or
  volume mounts; PVC mounts optionally.
- cert-manager mode emits a Certificate CRD (+ optional issuer) without forcing it
  when only an existing TLS secret is referenced.
- Presets: Basic Web App, Web App + Service, Web App + Ingress, Production Web App,
  Full Stack App, App + ConfigMap + Secret, App + Ingress + TLS, Production App + HPA.
- Per-resource tabs plus combined multi-document YAML, line numbers, copy/download
  per tab, Generate All / Reset, inline validation that gates generation while
  keeping the last valid preview.
- Legacy `kd-*` ids and toggle behavior preserved unchanged.

### Verified
- KUBERNETES suite grew 11 → 44 assertions.

## [2.2.0] - 2026-08-24 — Dockerfile Generator: multi-language upgrade (`53170b6`)

### Added
- Configuration-driven engine supporting 12 runtimes: Node, Python, Go,
  Java (JAR/Maven/Gradle), PHP, Ruby, Rust, .NET/C#, C/C++ and static sites.
- Dynamic per-language form fields with values preserved across language switches;
  language icon badge in the selector.
- Tabs for Dockerfile / .dockerignore / optional docker-compose.yml; copy/download
  follow the active tab.
- Inline validation (port range, version format) with last-good preview behavior.
- Generate/Reset actions, CSS-counter line numbers that don't pollute copied output.
- Multi-stage builds per language; healthchecks via busybox wget on Alpine bases.

### Fixed
- Generators silently falling back to defaults when called with string field ids.

### Verified
- DOCKER suite grew 16 → 39 assertions; legacy Node contract preserved.
