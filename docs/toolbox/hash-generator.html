toolbox/Security/hash generator

Hash generator 

SHA-1/256/384/512 digests via the Web Crypto API, unicode-safe.

about this tool

Computes SHA family digests with the browser’s native crypto.subtle — UTF-8 encoded, so multilingual input round-trips correctly. All four widths update as you type.

For checksums prefer SHA-256 or better; SHA-1 remains for legacy interop only.

hash sha256 sha512 checksum
