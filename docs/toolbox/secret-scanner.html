toolbox/Security/secret scanner

Secret scanner 

Find AWS keys, tokens, private keys and leaked creds in pasted text.

about this tool

Nine rule families (AWS keys, GitHub/Slack/Google tokens, JWTs, private-key blocks, credentialed URLs, suspicious env vars) plus a Shannon-entropy sweep for high-randomness values.

Matches are masked before display and placeholders like xxxx are ignored — safe to paste config files. Nothing leaves the browser.
