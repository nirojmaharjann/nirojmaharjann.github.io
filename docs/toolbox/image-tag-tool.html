toolbox/Docker/image tag reference tool

Image tag & reference tool 

Split or assemble registry/image references and sanity-check tags.

Docker treats the first dot-or-colon segment before / as a registry. No registry → Docker Hub; no tag → :latest (avoid it in production).

about this tool

Docker reference syntax has sharp edges: the first dotted-or-colon segment before a slash is a registry, no tag means :latest, and digests pin immutable versions. Paste a reference to decompose it, or build one from parts.

Avoid :latest in production — rollbacks become guesswork.
