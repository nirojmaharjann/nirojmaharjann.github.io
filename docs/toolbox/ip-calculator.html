IP / CIDR calculator 

Subnet math: masks, ranges, broadcast, usable hosts and child splits.

child subnets 
// choose a split size above

Usable hosts exclude the network and broadcast addresses. A /23 gives 510 usable hosts; a /30 gives exactly 2 — the classic point-to-point size.

about this tool

Enter any IPv4 CIDR to get mask, network/broadcast addresses, usable range and host count; then split it into equal child subnets down to a target prefix — VLSM planning in two clicks.

The split respects alignment: children are carved from the network address, not from arbitrary offsets.
