ARN builder & parser 

Decode arn:partition:service:region:account:resource strings, or assemble them.

or build one

Resource shapes differ per service: IAM uses role/path/name, S3 uses bucket/key. The parser shows the raw segments so nothing is hidden.

about this tool

Paste any ARN to split it into partition, service, region, account and resource path — invalid shapes are flagged instead of silently mis-parsed. Or fill the parts to build one.

Resource sections vary wildly per service (role/path/name vs bucket/key); the parser shows them raw so nothing is hidden.
