// about-me

$ cat about.md

I'm a DevOps engineer who treats infrastructure as a product. My day-to-day revolves around designing cloud architecture on AWS, containerising workloads with Docker, running them on Kubernetes, and making deployments boring — in the best possible way.

I believe every manual step is a bug waiting to happen, so I codify everything with Terraform, Ansible and CI/CD pipelines. When something breaks at 2 AM, good monitoring and alerting mean I already know before anyone pages me.

Away from the terminal I write about what I learn — check out the blog for notes on cloud, containers and automation.
